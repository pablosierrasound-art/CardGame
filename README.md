# Dungeon Keeper TD

Tower defense inverso en Phaser 3 + Vite. Defiende tu tesoro frente a oleadas de aventureros.

## Prototipo

- Toca una defensa del panel derecho y después una pared de la mazmorra para construir.
- Defensas: esqueleto, goblin y trampa de pinchos.
- Pulsa **Iniciar oleada** para recibir aventureros.
- Obtén oro derrotando enemigos y protege los 10 puntos de tesoro.

## Desarrollo

```bash
npm install
npm run dev
```
